# Bible Clock
Home Screen clock widget that shows a Bible verse matching the time (KJV, public domain).
3:16 -> John 3:16 · 4:13 -> Philippians 4:13 · 11:29 -> Jeremiah 29:11 (hour:minute = chapter:verse).
If that chapter:verse doesn't exist, it tries minute:hour (10:59 -> Psalm 59:10). On the hour (:00) it shows a verse about time.
